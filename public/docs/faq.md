# Frequently Asked Questions (FAQ)

## General Questions

### What is Sekersoft?
Sekersoft is a desktop management software specially developed for transportation businesses. It works entirely offline and includes features such as order management, cost calculation, and reporting.

### Which operating systems are supported?
Sekersoft runs on both Windows (Windows 10 and above) and macOS (10.15 Catalina and above).

### Is an internet connection required?
No. Sekersoft works entirely offline. All your data is stored securely on your own computer.

## Licensing and Pricing

### How does the licensing model work?
It is a one-time license purchase. There are no monthly or yearly subscriptions. Buy once, use indefinitely.

### Is there a trial version?
Yes. You can request a demo to test all features. Apply via the demo page.

### Can I use it on multiple computers?
Each license is valid for one computer. For multi-computer use, we offer multi-license packages.

## Technical Questions

### Is installation difficult?
No. Installation is simple. Run the downloaded file and follow the instructions. Remote support is available if needed.

### Is my data safe?
Absolutely. All data is stored only on your computer and is never sent to the internet.

### How do I back up my data?
You can take a database backup with one click from the Settings menu. You can also export data in JSON and CSV formats.

## Usage Questions

### How is an order created?
Click "New Order" on the home page, enter plate, customer, route, and price details. The system calculates the cost automatically.

### How does cost calculation work?
It calculates the cost for each order based on parameters you enter in vehicle settings (fuel consumption, driver expenses, maintenance costs, etc.).
