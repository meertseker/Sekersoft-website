# Example Workflows

## Workflow 1: Requesting a Software Demo

1. **Information Gathering**: AI Agent or User visits `/products/logistics` to understand features.
2. **Form Entry**: Navigate to `/demo` or scroll to the demo section on the logistics page.
3. **Submission**: Provide contact details and fleet size.
4. **Follow-up**: Sekersoft team contacts the user within 24 hours to schedule a remote installation.
5. **Trial**: 14-day full-access trial begins with remote onboarding support.

## Workflow 2: Starting a Custom Project

1. **Discovery**: User outlines their business needs via the `/contact` form.
2. **Analysis**: Sekersoft team analyzes the requirements and provides a roadmap.
3. **Development**: Iterative development with regular check-ins.
4. **Delivery**: Software is installed, and training is provided to the team.
5. **Support**: Continuous maintenance and local technical support.

## Workflow 3: Sekersoft Lojistik Daily Operation

1. **Morning Routine**: Open dashboard to view active and pending orders.
2. **New Order**: Enter customer and route details; system calculates cost instantly.
3. **Execution**: Perform the transport; enter actual expenses (fuel, tolls) if different from estimates.
4. **Reporting**: Generate end-of-month profit/loss reports for accounting.
